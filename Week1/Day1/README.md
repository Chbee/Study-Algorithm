## 💡 배운 점
- 완전탐색의 핵심: 모든 경우의 수를 확인하는 방법
- 시간복잡도별 N의 한계 (O(N²) ≤ 10,000, O(N³) ≤ 500)
- 조합과 순열의 차이: 순서 중요 여부
- 재귀를 활용한 조합 구현 (헬퍼 함수 패턴)
- 비트마스크의 원리: 2^N개의 부분집합을 비트로 표현
- `1 << n = 2^n`, AND 연산을 통한 비트 확인

## ⚠️ 어려웠던 점

- 순열 구현 시 visited 배열 관리
- 비트마스크의 AND 연산 원리 이해
