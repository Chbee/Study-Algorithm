## 💡 배운 점
- 언제 DP라고 판단해볼 수 있는가?
  1. 최댓값/최솟값/경우의 수 + 선택이 반복
    - 최대 이익, 최소 비용, 가장긴/가장 짧은과 같이 **최댓값**, **최솟값**이거나
    - 몇가지 방법, 선택하거나/안하거나, 하나 고르고 다음으로 넘어가고와 같이 **경우의수**일때
    - 핵심은 **현재 선택이 미래 결과에 영향을 주는데, 중복없이 미래를 선택해야 할때**
  2. 앞에서부터/끝까지 누적되며 결정되는 구조
    - i번째까지 고려했을 때 최적
    - N까지 도달하는 최소/최대
    - 연속/비연속, 구간 누적,
    - 보통 dp[i] 같은 1차원으로 잡히거나, 마지막 상태가 중요하면 dp[i][last]의 형태가 됨
  3. 입력 범위가 완전 탐색으로 진행 가능한 범위가 초과할때
    - N이 10만이면 완전 탐색 불가능
    - 대신 이전 결과를 재사용 할 수 있을 것 같은 규칙이 보이면 DP 후보
  4. 부분 문제로 쪼개면 똑같은 질문이 반복되는 느낌
    - 재귀로 생각했을 때 같은 index, 상태로 자꾸 돌아오는 문제
- DP의 시간복잡도
  1. 1차원 DP
    - dp[i]를 i=1...N으로 채움
    - 전이가 O(1)이면: **O(N)**
    - 전이가 이전 여러개를 훑으면 (예. j를 다봄): **O(N^2)**
  2. 2차원 DP
    - dp[i][j] 상태가 N*M이면 보통 O(NM)
    - 전이에서 또 k를 도는 순간 O(NMK)
  3. 3차원 DP
    - DP가 처리 가능한 범위 넘을 가능성 높음
- 점화식 세우는 방법
#### Step 1. 상태(state)를 한 문장으로 정의하기
예시:
- dp[i] = i번째까지 봤을 때 얻을 수 있는 최대값
- dp[i] = i에 도달하는 최소 비용
- dp[i][j] = i번째까지 고려했을 때, j상태일 때의 최적
여기서 **i가 뭘 표현하는지**에 대한 연습이 필요

#### Step 2. 마지막 행동 관점으로 쪼개기
점화식을 세우는곳에서 막히면 생각해볼것:
__"최적의 답을 도출하기위한 마지막 선택은 무엇이었을까?"__
__"마지막 선택이 A면 이전은 어떤 상태여야 하지?"__

예:
- 마지막에 상담을 했다면 → 그 상담 시작 전 날의 dp가 필요
- 마지막에 물건을 넣었다면 → 남은 무게의 dp가 필요
- 마지막 글자가 같다면/다르다면 → 이전 (i-1, j-1)이나 (i-1, j), (i, j-1) 필요

#### Step 3. 초기값/불가능 상태를 명시하기
- dp[0]은 무엇인가?
- 도달 불가능이면 최대화, 최소화, 경우의 수 중 무엇으로 둘 것인가?
- 경계(i - 1이 음수, 배열 범위 등) 처리는 어떤 방식으로 할 것인가?

#### Step 4. 계산 순서를 점화식에서 결정하기
- dp[i]가 dp[i-1]에 의존 -> i 증가 방향
- dp[i]가 dp[i+something]에 의존 -> 뒤에서 앞으로

#### 문제 풀기전에 항상 점화식 먼저 접근할것
1. 상태 정의: dp[ ]는 무엇
2. 전이: dp[ ] = …
3. 초기값/불가능값
4. 루프 방향/정답 위치
