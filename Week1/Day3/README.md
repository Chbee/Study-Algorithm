## 💡 배운 점
- 표준 시간복잡도 패턴 정리 (Notes 기준)
- BFS/DFS(그래프/격자): O(V+E) = 격자면 O(N*M)
- 이진 탐색: O(log N) (정렬 필요시 O(N log N) 추가)
- DP: 점화식 1회 갱신 기준 O(N) 또는 O(N*M)
- 백트래킹: 최악 O(N!) 또는 O(N^N) (가지치기에 따라 감소)
- 다익스트라(힙): O(E log V)
- 플로이드-워셜: O(V^3)
- MST: Kruskal O(E log E), Prim(힙) O(E log V)
- 그리디: 보통 O(N) 또는 정렬 포함 O(N log N)
- 시뮬레이션(격자): 보통 O(N*M) (각 칸/이동 1회 기준)
- 투포인터: O(N) (정렬 필요시 O(N log N) 포함)
- Int 범위: Swift Int(64-bit) 최대 약 9e18까지 값 저장 가능 (연산 횟수와는 별개)
