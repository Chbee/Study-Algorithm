## 📚 학습 내용

### 이론
- 이진탐색 기본 구조: lo/hi/mid 갱신 규칙, 종료 조건 정리
- lower/upper bound 개념과 처음으로 만족하는 위치 찾기
- 결정 문제를 위한 파라메트릭 서치 흐름 (가능/불가능 조건 판단 함수)
- 자주 하는 실수: 경계값, 무한 루프, 오버플로우 방지
- 시간 복잡도: 정렬된 배열 O(log N), 파라메트릭 서치 O(log 범위 * 판정 함수)
