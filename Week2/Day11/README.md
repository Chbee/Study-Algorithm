## 📚 학습 내용

### 이론
- 2차원 DP는 상태 축이 2개인 DP로, `dp[i][j]`를 문장으로 명확히 정의하는 것이 핵심
- 축 하나는 보통 진행/순서(i), 다른 하나는 제약/조건/위치(j)로 두며 전이는 이전 상태에서 온다
- 대표 패턴: 격자 이동형, 선택/비선택+개수축, 두 시퀀스 비교형, 구간형
- 작은 예제에서 상태/전이/초기값을 직접 설계해보며 감각을 잡는다
- 자주 막히는 포인트: 상태 정의 모호, 전이 불일치, 초기값 누락, 인덱스 혼용
- 일반적인 시간복잡도: O(N*M) (상태 수만큼 전이를 한 번씩 계산하는 경우)
