### 순열과 조합의 차이

- **순열 (Permutation)**: n개 중 r개를 **순서 있게** 나열. `[1,2]`와 `[2,1]`은 다른 경우. → nPr = n! / (n-r)!
- **조합 (Combination)**: n개 중 r개를 **순서 없이** 선택. `[1,2]`와 `[2,1]`은 같은 경우. → nCr = n! / (r! × (n-r)!)
- **중복 순열**: n개 중 r개를 중복 허용하여 순서 있게 나열. → n^r
- **중복 조합**: n개 중 r개를 중복 허용하여 순서 없이 선택. → (n+r-1)! / (r! × (n-1)!)

예) {1, 2, 3}에서 2개를 뽑을 때:
- 순열: `[1,2] [1,3] [2,1] [2,3] [3,1] [3,2]` → 6가지 (3P2)
- 조합: `[1,2] [1,3] [2,3]` → 3가지 (3C2)

### 순열과 조합 백트래킹 패턴 정리

순열/조합 문제는 모두 DFS + 백트래킹 구조이지만, **두 가지 요소**에 따라 코드가 달라진다:
1. **순서가 중요한가?** (순열 vs 조합)
2. **중복 선택이 가능한가?** (중복 허용 vs 비허용)

#### 패턴 비교표

| 유형 | 순서 | 중복 | visited 배열 | start 파라미터 | 다음 호출 | 문제 예시 |
|------|------|------|:---:|:---:|------|------|
| 순열 | O | X | **O** | X | `dfs()` (1~N 전체 순회) | 15649(1), 10974 |
| 조합 | X | X | X | **O** | `dfs(i + 1)` | 15650(2), 15655(6) |
| 중복순열 | O | O | X | X | `dfs()` (전체 순회) | 15656(7) |
| 중복조합 | X | O | X | **O** | `dfs(i)` ← 자기자신 재사용 | 15657(8) |

#### 1. 순열 (중복 X) - BOJ-15649, BOJ-10974

```swift
var visited = [Bool](repeating: false, count: n + 1)
func dfs() {
    for i in 1...n {           // 매번 1부터 전체 순회
        if visited[i] { continue }
        visited[i] = true      // 방문 처리
        temp.append(i)
        dfs()
        temp.removeLast()
        visited[i] = false     // 방문 해제
    }
}
```
- **핵심**: `visited` 배열로 이미 선택한 원소를 제외
- 매번 전체를 순회하므로 `[2,1]`과 `[1,2]`가 모두 나옴 → 순서가 다르면 다른 수열

#### 2. 조합 (중복 X) - BOJ-15650, BOJ-15655

```swift
func dfs(_ start: Int) {
    for i in start..<n {       // start부터 순회
        temp.append(nums[i])
        dfs(i + 1)             // 다음 원소부터 탐색
        temp.removeLast()
    }
}
```
- **핵심**: `start` 파라미터로 이전 원소는 아예 보지 않음
- `i + 1`을 넘기므로 같은 원소 재사용 불가
- visited 배열 불필요 — start가 자연스럽게 오름차순 보장

#### 3. 중복 순열 - BOJ-15656

```swift
func dfs() {
    for i in 0..<n {           // 매번 전체 순회
        temp.append(s[i])
        dfs()                  // 제한 없이 다시 전체 탐색
        temp.removeLast()
    }
}
```
- **핵심**: visited도 없고 start도 없음 → 완전 자유 선택
- 같은 원소를 여러 번 고를 수 있고, 순서도 구분함

#### 4. 중복 조합 - BOJ-15657

```swift
func dfs(start: Int) {
    for i in start..<n {       // start부터 순회
        temp.append(s[i])
        dfs(start: i)          // i+1이 아닌 i를 넘김!
        temp.removeLast()
    }
}
```
- **핵심**: 조합과 거의 같지만 `dfs(i)`로 자기 자신을 재사용 허용
- `i + 1` vs `i`의 차이가 "중복 허용 여부"를 결정

#### 요약: 코드 변경 포인트 2가지

```
순서가 중요? → YES: 매번 전체 순회 (visited로 제어)
              → NO:  start 파라미터 사용

중복 허용?   → YES: visited 제거 / dfs(i) 사용
              → NO:  visited 유지 / dfs(i+1) 사용
```
