### 이론
- 위상정렬: 선행 조건이 있는 작업을 규칙 위반 없이 나열 (DAG 필수)
- 위상정렬 조건: 진입차수 0부터 시작, 모든 노드 처리되면 성공, 일부만 처리되면 사이클
- Kahn 알고리즘: indeg 0 큐 → pop → 간선 제거 → 새 indeg 0 추가 (O(V+E))
- 위상정렬+DP: 위상 순서가 안전한 계산 순서, dp[next] = max(dp[next], dp[cur] + cost[next])
- 투포인터 사용 판단: 포인터가 뒤로 가지 않으면 O(N), 단조성 없으면 불가
- 슬라이딩 윈도우: 양수 배열에서 sum 단조성 이용, target 이상이면 left 이동으로 축소
- 양끝 포인터: 정렬 후 합/차이 최소화, sum 부호로 left/right 이동
- 소수의 연속합 대비: 에라토스테네스의 체로 소수 리스트 생성 후 투포인터 적용
