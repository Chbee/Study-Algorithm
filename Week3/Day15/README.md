### 이론
- 우선순위 큐: 우선순위가 높은 요소를 먼저 처리하는 자료구조
- 힙 조건: 완전 이진 트리 + 부모/자식 간 우선순위(최대/최소 힙)
- 주요 연산: 삽입/삭제 O(log N), peek O(1)
- 구현 포인트: 배열 기반, 부모/자식 인덱스 계산으로 up-heap/down-heap
