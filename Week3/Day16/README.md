### 이론
- 유니온 파인드(DSU): 여러 집합을 빠르게 합치고(find/union), 같은 집합 여부를 판별하는 자료구조
- 대표(루트) 개념: 같은 집합이면 find 결과(루트)가 동일
- 경로 압축(Path Compression): find 과정에서 경로를 눌러 트리 높이를 줄여 성능 개선
- union by size/rank: 작은 트리를 큰 트리에 붙여 트리 높이를 최소화
- 시간복잡도: 경로 압축 + union by size/rank 기준, m번 연산이 O(m α(n))로 거의 O(1)
- 파티/연결 문제에 적용 시: 같은 그룹으로 묶은 뒤 대표만 비교하면 됨
